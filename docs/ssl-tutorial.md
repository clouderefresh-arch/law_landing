# Туториал: SSL для без-адвоката.рф

Сейчас браузер ругается, потому что на хостинге висит **самоподписанный** сертификат. Нужен бесплатный Let’s Encrypt из панели ISPmanager. Это 5–10 минут, SSH не нужен.

## Что должно получиться

`https://без-адвоката.рф/` открывается без предупреждения. Замок в адресной строке, издатель — Let’s Encrypt.

## 1. Войти в панель

Откройте любой из адресов (логин и пароль — от хостинга Reg.ru):

- https://server113.hosting.reg.ru/manager
- https://37.140.192.114:1500/ispmgr

Браузер может предупредить про сертификат самой панели — это нормально. Подтвердите переход.

## 2. Выпустить Let’s Encrypt

Два равноценных пути. Берите тот, что видите в меню.

### Через сайт (проще)

1. Раздел **Сайты**.
2. Выделите `без-адвоката.рф` → **Изменить**.
3. **SSL-сертификат** → **Новый бесплатный от Let's Encrypt**.
4. Включите **Перенаправлять HTTP-запросы в HTTPS**.
5. Сохраните. В форме выпуска:
   - **Wildcard** и **Проверка через DNS** — выключены
   - **Доменное имя:** `без-адвоката.рф` и `www.без-адвоката.рф` (это два разных имени)
   - **Почтовый ящик:** `nilich1972@mail.ru`
   - **Длина ключа:** 2048
6. Нажмите **Выпустить**. Пока заявка идёт, вторую не создавайте.

### Через список сертификатов

1. **SSL-сертификаты** → **Добавить сертификат** → **Let's Encrypt**.
2. Включите **Включить SSL-сертификат**.
3. **Домен** — сайт `без-адвоката.рф`.
4. **Доменное имя** — оба имени, как выше.
5. Почта и длина ключа — те же.
6. **Выпустить**.

## 3. Дождаться журнала

В списке сертификатов откройте запись → **Журнал**. Нужна строка вроде «Let’s Encrypt сертификат успешно получен».

Пока заявка обрабатывается, панель ещё может показывать самоподписанный — это не ошибка.

## 4. Включить редирект, если его не было

**Сайты** → сайт → **Изменить** → **Перенаправлять HTTP-запросы в HTTPS** → сохранить.

По желанию включите HSTS.

## 5. Проверить

Откройте в обычном окне (не «продолжить на сайт»):

- https://без-адвоката.рф/
- https://www.без-адвоката.рф/

Замок без предупреждения. По http:// должен быть переход на https://.

Издателя можно глянуть:

```bash
echo | openssl s_client -connect xn----8sbaabinfs8a6byc.xn--p1ai:443 -servername xn----8sbaabinfs8a6byc.xn--p1ai 2>/dev/null | openssl x509 -noout -issuer
```

Должно быть Let’s Encrypt / ISRG, а не `CN = xn----8sbaabinfs8a6byc.xn--p1ai`.

## Если не выпустился

- В журнале сертификата — текст ошибки.
- A-записи `без-адвоката.рф` и `www` смотрят на `37.140.192.114`.
- Сайт открывается по **http://** (проверка Let’s Encrypt идёт по HTTP).
- Ничего не режет путь `/.well-known/acme-challenge/`.
- Не жмите «Выпустить» пачкой: у Let’s Encrypt лимит заявок.

Продление дальше делает панель сама, примерно раз в 60–90 дней.

## Скрипт из репозитория

Тот же выпуск, если удобнее из терминала (логин панели, не в чат):

```bash
export ISP_USER='логин'
export ISP_PASSWORD='пароль'
python3 deploy/issue-ssl.py
```
