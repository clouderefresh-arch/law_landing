# Скриншоты сайта без-адвоката.рф

PNG-снимки живого лендинга [без-адвоката.рф](https://без-адвоката.рф) («Как выиграть суд без адвоката?»).

Снято 6 ноября 2026: без потерь, Retina **2×** на компьютере и планшете, **3×** на телефоне. Шрифты и портрет дождались загрузки, анимация отключена.
